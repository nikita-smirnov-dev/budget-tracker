# Мой бюджет — Трекер личных финансов

Простое, быстрое и удобное приложение для учета личных финансов и отслеживания текущего баланса. Проект разработан на современном веб-стеке с фокусом на независимую архитектуру компонентов, строгую типизацию и адаптивность под любые экраны.

## Стек технологий

- **Фреймворк:** Vue 3 (Composition API)
- **Язык:** TypeScript
- **Стилизация:** Чистый CSS, методология БЭМ, Flexbox, CSS Grid
- **Сборщик:** Vite

## Функционал приложения

- **Управление балансом:** Отображение текущего финансового состояния, динамический пересчет общей суммы при добавлении или удалении операций.
- **Фиксация транзакций:** Раздельный учет доходов и расходов с указанием названия и суммы.
- **Система тегов и шаблонов:** Быстрое заполнение формы в один клик с помощью частых транзакций, а также возможность создавать и сохранять свои собственные кастомные теги.
- **Фильтрация и история:** Удобный просмотр истории операций с группировкой по датам и возможностью мгновенного удаления ошибочных записей. Поддерживается фильтрация по типу операции (Все / Доход / Расход).
- **Глобальная мультивалютность:** Выбор базовой валюты приложения (RUB, USD, EUR, CNY) с автоматической изоляцией радиокнопок на разных разрешениях экрана.

## Архитектурные особенности проекта

- **Вынос бизнес-логики (Composables):** Все ключевые процессы (логика транзакций, управление тегами, логика смены валют) полностью вынесены из UI-компонентов в чистые, переиспользуемые composables-функции.
- **Строгая типизация (TypeScript):** Архитектура данных полностью завязана на строгие интерфейсы. Для обработки типов валют и исключения рантайм-ошибок реализована проверка на исчерпываемость (Exhaustiveness Check) с использованием типа `never`.
- **Продвинутый адаптивный UI:** Интерфейс бесшовно адаптируется от мониторов до экранов компактных смартфонов (до 310px). На планшетах и мобильных устройствах десктопная форма ввода трансформируется в эргономичное модальное окно с использованием встроенного механизма `<Teleport>`, что гарантирует стабильность CSS-стилей и высокую доступность (A11y).

## Инструкция по запуску проекта

Для запуска приложения на локальном компьютере вам понадобятся установленные **Node.js** и менеджер пакетов **npm** (или **pnpm**).

1. **Установите все зависимости:**

   ```bash
   npm install
   ```

2. **Запустите сервер для разработки:**

   ```bash
   npm run dev


   ```

3. **Сборка проекта для продакшена (деплоя):**
   ```bash
   npm run build
   ```
